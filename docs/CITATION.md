# Citation

Cite this software by its repository URL, release version, and commit identifier:

LiteratureAgent, version 2.2.0. https://github.com/Jordanmarshall-utk/LiteratureAgent

The manuscript's approved author list, bibliographic citation, and publication
DOI have not been supplied. They are not inferred from repository account
names. Machine-readable manuscript citation metadata can be added when those
details are confirmed.

Version 2.2.0 is published before journal submission with manuscript citation
metadata explicitly pending. The repository URL, release version, and source
commit remain the software citation identifiers; no journal acceptance,
publication DOI, or approved manuscript author list is implied.

The source records for the SHAP method and the literature-data comparison are
provided in `manuscript/references/corrected_citation_records.bib` and `.ris`.
Those records identify cited work; they do not establish authorship of this
repository. Cite the underlying perovskite data independently of the software.
