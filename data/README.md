# Data

`Perovskite_database_content_all_data.csv` is the baseline table used by the
default application configuration and downstream PCE/stability workflow.

The literature-expansion corpus, extracted PDFs, evidence packets, and other
model or manuscript artifacts are intentionally not committed. The narrow
`data/figure5/` exception contains the complete-cohort exact-interventional grouped-SHAP and narrow choice-bundle tables, limited
row-level display context, solvent-formulation summaries, and validation
metadata needed to reproduce four independent single-panel interpretation
figures. It does not include the full 278-predictor modeling rows. Verify the
baseline dataset's original citation and redistribution terms before public
release.
